# Vara viva: no anclarse a lo que hizo un modelo peor

Un archivo viejo trae el techo del modelo que lo hizo. Si se abre como plantilla, el modelo de hoy hereda ese techo:
copia la rejilla, las tarjetas planas y la jerarquía tímida, y entrega algo «correcto» que está por debajo de lo que
sabe hacer. Es un anclaje: la primera imagen que ve fija hasta dónde se atreve.

**La vara es lo mejor que se ha logrado AHORA, no lo primero que existe en la carpeta.**

## Cómo se aplica (toda pieza visual: video, HTML, panel)

1. **El contenido se reutiliza; la forma no.** De una pieza vieja se extrae el texto y la estructura de ideas. La
   parte visual nace en blanco, con libertad total, como pide `invocacion.md`.
2. **Ideas a ciegas primero.** El agente propone su forma antes de mirar cualquier pieza previa del mismo tema.
3. **Las referencias son piso, no plantilla.** Si tu dueño trae un video que le encantó, se usa para medir («¿lo
   nuestro está a esa altura o arriba?»), no para copiar su composición.
4. **Marca sí, maqueta no.** Si tu dueño tiene paleta y tipografía, se respetan; no dictan composición.
5. **Prueba antes de entregar:** si se ve como un documento con cajas, falta otra ronda. Lo plano no se entrega.
