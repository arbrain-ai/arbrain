# dolor/: la alarma que llega directo

Vacía a propósito. Aquí va lo que nunca puede esperar: lo vital que, si se rompe, debe avisarte en ese momento
(cobros que fallan, un cliente grande enojado, el sistema caído). Pocas alarmas y verdaderas: una alarma que suena
por todo deja de oírse.

Un archivo por alarma: qué la dispara, cómo te llega y qué haces cuando suena.
