# sentidos/: lo que tu cerebro vigila por ti

Vacía a propósito. Aquí van las ideas de qué debe vigilar tu cerebro y con qué umbral: ventas del día, mensajes de
clientes, una métrica que no debe caer. Un buen sentido deja pasar solo lo que te cambia una decisión; lo demás es
ruido y se filtra.

Un archivo por sentido: qué mira, dónde lo lee, cada cuánto y qué hace cuando algo cruza el umbral.
