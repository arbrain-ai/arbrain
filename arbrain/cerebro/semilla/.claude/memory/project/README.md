# project/: en qué estás

Proyectos, lanzamientos y decisiones con fecha: qué se firmó, qué falta, dónde vive el trabajo. Un archivo por
proyecto o por decisión grande (`lanzamiento-curso-2026-11-01.md`).

Escribe lo firmado con las palabras del dueño y separa lo que es idea de lo que es decisión. Lo que se pueda
leer en el código, en una base o en una herramienta conectada no se copia aquí: se apunta a la fuente. Con más
de 90 días sin uso, su línea pasa a `MEMORY-archivo.md`.
