# feedback/: correcciones y preferencias

Cada vez que el dueño corrige a Levy o dice «así no» o «así sí», va aquí: la regla, sus palabras textuales, el
porqué y cómo aplicarla. Un archivo por regla (`una-recomendacion-cerrada-2026-10-11.md`).

Las correcciones que deben pesar siempre suben como una línea a «Reglas vivas» de `MEMORY.md`. Lo que salió
bien también cuenta: confirmar un acierto evita perderlo.
