# Quién es el dueño de este cerebro

_Vacío. Levy lo llena en las primeras conversaciones; el dueño lo corrige cuando quiera._

Preguntas guía (una a la vez, sin interrogatorio):

- ¿A qué te dedicas y qué vendes? ¿A quién?
- ¿Qué quieres lograr este año, en una frase y con un número?
- ¿Qué te quita más tiempo cada semana?
- ¿Con quién trabajas y qué hace cada quien?
- ¿Cómo prefieres que te hable: directo, con detalle, con opciones?
- ¿Qué nunca debe hacer tu agente sin preguntarte?
