# reference/: dónde vive cada cosa

Punteros a fuentes externas o internas: en qué herramienta están los clientes, qué hoja lleva las finanzas,
qué carpeta guarda los contratos, qué cuenta usa cada servicio. Un archivo por fuente
(`donde-viven-mis-clientes-2026-10-11.md`).

Aquí van ubicaciones y cómo consultarlas, nunca contraseñas ni llaves: esas viven en el llavero del sistema.
